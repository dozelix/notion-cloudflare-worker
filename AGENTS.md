# AGENTS.md — notion-cloudflare-worker

## Qué es
Cloudflare Worker para integración con la API de Notion.

## Stack
- JavaScript (Cloudflare Workers)
- Notion API (`@notionhq/client`)
- Wrangler + Vitest

## Comandos
```bash
npm run deploy       # wrangler deploy
npm run dev          # wrangler dev
npm run test         # Vitest
```

## Convenciones
- Rama: `main` (deploy automático)
- Commits en español
